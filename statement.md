# Project Statement

## Problem Statement

Managing basic hotel activities such as customer registration, room booking, food ordering, billing, and checkout manually can be time-consuming and may lead to errors in maintaining customer information and calculating charges. Hotel staff need to repeatedly record customer details, select appropriate rooms, calculate room charges based on the number of days, add food expenses, and prepare the final bill.

The **Hotel Management System using Python** addresses this problem by providing a simple menu-driven application for managing these basic hotel operations. The system allows the user to add customer details, view customer records, book rooms, calculate food bills, and generate the final bill during checkout. It aims to make basic hotel management activities more organized, faster, and easier to handle while demonstrating fundamental Python programming concepts.

## Objectives

* Design a simple Python-based hotel management system that handles basic customer and billing operations.
* Allow users to add and store customer information such as name and phone number.
* Provide different room categories such as Single, Double, and Deluxe with predefined room charges.
* Calculate room charges based on the selected room type and number of stay days.
* Provide a basic food menu and calculate food charges according to the selected item and quantity.
* Maintain separate room and food bills for each active customer.
* Calculate and display the total amount during customer checkout.
* Validate important user inputs such as room selection, food selection, number of days, and food quantity.
* Use Python concepts such as functions, lists, dictionaries, loops, conditional statements, input/output, and arithmetic operations.
* Provide clear messages and menu options so that the system is easy to operate and understand.

## Scope of the Project

### Functional Scope

* **Customer Management:** Add customer details and maintain customer records during the program execution.
* **Customer Display:** Display the details of customers currently stored in the system.
* **Room Booking:** Provide Single, Double, and Deluxe room options and calculate the room bill according to the selected room and number of days.
* **Food Billing:** Provide Breakfast, Lunch, and Dinner options and calculate food charges based on quantity.
* **Bill Management:** Maintain room charges and food charges separately for each customer.
* **Checkout:** Calculate the final bill by combining the customer's room bill and food bill and display the complete billing information.
* **Input Validation:** Prevent invalid room and food selections and reject non-positive values for stay duration and food quantity.
* **Menu-Driven Operation:** Provide a continuous menu through which the user can perform different hotel management operations until the Exit option is selected.
* **In-Memory Storage:** Store active customer information using Python lists and dictionaries during program execution.

### Non-Functional Scope

* **Performance:** Complete basic customer, room, food, and billing operations quickly without unnecessary processing.
* **Portability:** Use standard Python features so that the program can run on systems with a compatible Python 3 installation.
* **No External Dependencies:** Keep the basic application lightweight and avoid requiring external Python libraries.
* **Usability:** Provide simple menu options, clear instructions, and readable billing output for easy operation.
* **Reliability:** Validate important inputs and display appropriate messages when invalid choices or unavailable customer records are entered.
* **Maintainability:** Organize the application into separate functions so that individual features can be modified or extended easily.
* **Offline Operation:** Allow the basic hotel management functions to work without an internet connection.

## Target Audience

* **Students:** Computer science and engineering students who want to understand how Python programming concepts can be applied to a real-world management problem.
* **Hotel Staff:** Small-scale hotel or reception staff who need a simple system for managing basic customer, room, food, and billing information.
* **Python Beginners:** Learners who want to practice functions, lists, dictionaries, loops, conditional statements, and input/output through a practical project.
* **Academic Demonstrations:** Students and instructors who need a simple Python-based project for demonstrating problem-solving and programming concepts.
